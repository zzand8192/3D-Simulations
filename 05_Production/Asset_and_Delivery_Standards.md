# Asset and delivery standards

## Working delivery proposal

Vertical 1080 x 1920, 30 fps, with a platform-compatible MP4 review or delivery export. These settings are starting recommendations, not a measured requirement from audience data. Confirm the target platform and editor settings for each release. Preserve a higher-quality master when the production workflow supports it.

## Asset record

Every reusable character, environment, prop, effect, font, and audio file should have a short record containing asset ID, filename, source or creator, selected usage terms, editable source location, version, approval state, and episodes used. The register starts blank. Reference footage has a separate source manifest.

## Reusable production elements

Prioritize the opening-question treatment, metric display, closing card, camera rigs, common crowd actions, a small set of locations, ordinary props, and Greg's eventual model. Record how to replace values and colors so an AI or collaborator can use the system without rebuilding it.

## Output record

For each delivery, record episode ID, export filename, version, resolution, fps, duration, audio presence, review date, and selected platform. Identify the script and shot-list versions used. Review the actual export.

## Storage

Keep working files within the episode folder. Keep source videos in the reference library. Place finished exports inside the episode's delivery folder. Back up the project and the approved model source before major revisions. Record backup location and date when performed.
