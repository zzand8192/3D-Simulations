## How simulations are organized

Use the `studio-bible` branch as the working branch. Keep each simulation in its own folder under `simulations/`, with its script, scenes, animation, and exports together.

The intended project layout is:

```text
01_Studio_Strategy/ ... 10_Previous_Project/   Shared studio notes and references
shared/                                     Reusable characters, props, and tools
simulations/
  what-if-underwater/
  what-if-cars-couldnt-stop/
  what-if-everyone-could-fly/
```

The `shared/` and `simulations/` folders can be created when production begins. The recovered underwater source is currently in `10_Previous_Project/what-if-underwater/`.
